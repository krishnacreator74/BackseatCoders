## [0.1.0] - 2026-11-27

### Added
- AI-powered code reactions triggered when saving files.
- Multiple AI personalities with unique reactions.
- Local LLM support through LM Studio and Ollama.
- Automatic model discovery.
- Configurable AI provider and API endpoint.
- Model selection and persistence.
